Anleitung: Gruppe & Mission

So macht ihr gemeinsam mit — eine Gruppe beitreten/erstellen und eine Mission anlegen. Für Schüler:innen.

Das Wichtigste zuerst: BIOGLOW speichert alles zuerst nur auf deinem Gerät. Damit andere deine Gruppe, Funde oder Aktionen sehen, muss die Cloud einmal eingeschaltet werden.

Merksatz: Ohne Cloud = nur du siehst es. Mit Cloud + gleichem Gruppen-Code = alle sehen es.

Das erklärt drei Dinge, die sonst verwirren:

  • „Ich habe eine Aktion angelegt, aber niemand sieht sie." → Sie war lokal (Nur ich). Ohne Cloud wird nichts geteilt.
  • „Ich kann nicht auf Verbinden tippen / es passiert nichts." → Es fehlt der Beitritts-Code im Feld.
  • „Meine Gruppe sieht meine Funde nicht." → Ihr habt unterschiedliche Gruppen-Codes oder die Cloud ist aus.

Teil 1 · Eine Gruppe erstellen (einmalig, mit einer erwachsenen Person)

Eine „Gruppe" (= Klasse/AG/Team) braucht einmal eine Erwachsene, die die Cloud einrichtet. Danach machen alle Kinder nur noch mit einem Code mit.

  1. Cloud einrichten (Erwachsene, ~10 Min, einmalig): Anleitung SUPABASE_Anleitung_fuer_Kinder.md befolgen → ihr bekommt eine Supabase-URL und einen anon-Key.
  2. In BIOGLOW: Profil → Klasse & Cloud → 🔧 Für Lehrkräfte / Erweitert.
  3. Dort eintragen: Supabase-URL, anon-Key und einen Gruppen-/Klassencode ausdenken (z. B. 8b-2026).
  4. Auf „📤 Beitritts-Code für die Klasse teilen" tippen → es entsteht ein langer Code. Diesen an alle im Team schicken.

✅ Fertig – die Gruppe existiert. Der lange Code enthält Cloud-Zugang und Gruppencode zusammen.

💡 Nur die Erwachsene macht Schritt 1–4. Alle anderen machen Teil 2.

Teil 2 · Einer Gruppe beitreten (alle Kinder, 30 Sekunden)

  1. Den Beitritts-Code von der Lehrkraft kopieren.
  2. In BIOGLOW: Profil → Klasse & Cloud → 🔑 Mit Klassen-Code beitreten.
  3. Code ins Feld einfügen → auf „Verbinden" tippen.
  4. Es erscheint „Klasse verbunden! ☁️" – oben steht jetzt „☁️ Cloud aktiv · Gruppe …".

Wenn „Verbinden" nicht klappt:

  • Ist das Feld wirklich ausgefüllt? (Leeres Feld → „Bitte zuerst den Code einfügen".)
  • Hast du den ganzen Code kopiert (er ist lang)? Nichts abschneiden.
  • Bist du online? Für das erste Verbinden braucht ihr Internet.

Teil 3 · Eine Mission/Aktion erstellen

a) Fertige Missionen – schon in der App (Missionen-Tab), z. B. „Totholz-Ecke anlegen". Einfach machen und ein Beweisfoto hochladen.

b) Eigene Aktion (z. B. Müllsammeln, Gewässersäuberung):

  1. Tab Missionen → „🤝 Aktion erstellen & teilen".
  2. Titel eingeben (z. B. „Müllsammeln am Bach").
  3. Kurzbeschreibung: Was? Wo? Wann? (z. B. „Sa 10 Uhr, Treffpunkt Brücke").
  4. „Mit wem teilen?" wählen:
    • Nur ich (lokal) – bleibt auf deinem Gerät. Andere sehen sie nicht.
    • Meine Gruppe (per Code) – alle mit demselben Gruppen-Code sehen sie. (Cloud nötig.)
    • Öffentlich – alle im Umkreis – alle Nutzer:innen im gewählten Umkreis. (Cloud nötig.)
  5. „Aktion anlegen" tippen.
⚠️ Sind „Gruppe" und „Öffentlich" ausgegraut? Dann ist die Cloud noch aus → erst Teil 2 machen. Sonst kannst du nur „Nur ich" wählen und niemand sonst sieht die Aktion.

Teil 4 · Geteilte Aktionen finden & mitmachen

  1. Tab Missionen → „🌍 Geteilte Aktionen (Gruppe / Umkreis)".
  2. Du siehst: Aktionen deiner Gruppe (gleicher Code) + öffentliche Aktionen im Umkreis.
  3. Auf „Mitmachen" tippen → die Aktion landet in deinen Missionen.

Nichts zu sehen? Prüfe: gleiche Gruppen-Code-Schreibweise bei allen? Cloud aktiv (☁️)? Bei „öffentlich": Standort erlaubt und im Umkreis?

Teil 5 · Werden meine Fotos gespeichert?

Ja – aber datensparsam:

  • Auf deinem Gerät: Jedes Beweisfoto wird lokal gespeichert (Browser-Speicher IndexedDB). Es bleibt da, bis du es löschst (Backup/Restore im Profil).
  • In der Cloud/Gruppe: Es werden nur die Fund-Daten übertragen: Artname, Zeit, (bei gefährdeten Arten unscharfer) Standort, Status, Punkte, Anzeigename, Gruppencode. Das Foto selbst wird NICHT hochgeladen.
  • Für die Wissenschaft: Nur wenn du aktiv exportierst (Darwin-Core/CSV) oder zu iNaturalist sendest, gehen Daten weiter.
Kurz: Fotos = lokal gespeichert, aber nicht automatisch geteilt. Gut für den Datenschutz.
