Anleitung: Gruppe & Mission

So macht ihr gemeinsam mit — eine Gruppe beitreten/erstellen und eine Mission anlegen. Für Schüler:innen.

Das Wichtigste zuerst: BIOGLOW speichert alles zuerst nur auf deinem Gerät. Damit andere deine Funde oder Aktionen sehen, braucht ihr alle denselben Gruppencode. Die Cloud ist schon eingerichtet – ihr müsst nichts installieren und keine Schlüssel eintragen.

Merksatz: Ohne Gruppencode = nur du siehst es. Gleicher Gruppencode = alle in der Gruppe sehen es.

Das erklärt drei Dinge, die sonst verwirren:

  • „Ich habe eine Aktion angelegt, aber niemand sieht sie." → Sie war lokal (Nur ich) – oder du hattest noch keinen Gruppencode.
  • „Meine Gruppe sieht meine Funde nicht." → Ihr habt den Code unterschiedlich geschrieben oder du warst offline.
  • „Wo trage ich eine Supabase-URL ein?" → Gar nicht. In der App steht: „☁️ Zentrale Cloud aktiv – kein Setup nötig."

Teil 1 · Eine Gruppe erstellen (einmal, eine Person)

Eine Gruppe entsteht, sobald sich jemand einen Code ausdenkt und die anderen ihn eintippen. Mehr ist es nicht.

  1. Code ausdenken – am besten eine erwachsene Person. Nicht zu leicht zu erraten, klein geschrieben, ohne Leerzeichen.
  2. Den Code an alle in der Gruppe weitergeben (Zettel oder Messenger). Nicht öffentlich ins Internet stellen – wer den Code hat, sieht die Gruppe.

✅ Fertig – die Gruppe existiert, sobald die erste Person den Code eintippt.

💡 „🔧 Für Lehrkräfte / Erweitert" braucht ihr nicht. Das ist nur für Schulen, die eine eigene Cloud statt der zentralen verwenden.

Teil 2 · Einer Gruppe beitreten (alle, 30 Sekunden)

  1. In BIOGLOW: Profil → Klasse & Cloud.
  2. Dort steht „☁️ Zentrale Cloud aktiv – kein Setup nötig."
  3. Ins Feld „Gruppen-/Klassencode" den Code genau so eintippen, wie ihn alle benutzen.
  4. Darunter erscheint „Du bist in Gruppe …", unten „☁️ Cloud aktiv".

Wenn es nicht klappt:

  • Steht oben nicht „Zentrale Cloud aktiv"? App ganz schließen und neu öffnen.
  • Code genau gleich geschrieben wie alle anderen? Groß/klein und Bindestriche zählen.
  • Offline gemachte Funde werden nachgeschoben, sobald wieder Internet da ist.

Teil 3 · Eine Mission/Aktion erstellen

a) Fertige Missionen – schon in der App (Missionen-Tab), z. B. „Totholz-Ecke anlegen". Einfach machen und ein Beweisfoto hochladen.

b) Eigene Aktion (z. B. Müllsammeln, Gewässersäuberung):

  1. Tab Missionen → „🤝 Aktion erstellen & teilen".
  2. Titel eingeben (z. B. „Müllsammeln am Bach").
  3. Kurzbeschreibung: Was? Wo? Wann? (z. B. „Sa 10 Uhr, Treffpunkt Brücke").
  4. „Mit wem teilen?" wählen:
    • Nur ich (lokal) – bleibt auf deinem Gerät. Andere sehen sie nicht.
    • Meine Gruppe (per Code) – alle mit demselben Gruppen-Code sehen sie. (Cloud nötig.)
    • Öffentlich – alle im Umkreis – alle Nutzer:innen im gewählten Umkreis. (Cloud nötig.)
  5. „Aktion anlegen" tippen.
⚠️ Sind „Gruppe" und „Öffentlich" ausgegraut? Dann fehlt noch der Gruppencode → erst Teil 2 machen. Sonst kannst du nur „Nur ich" wählen und niemand sonst sieht die Aktion.

Teil 4 · Geteilte Aktionen finden & mitmachen

  1. Tab Missionen → „🌍 Geteilte Aktionen (Gruppe / Umkreis)".
  2. Du siehst: Aktionen deiner Gruppe (gleicher Code) + öffentliche Aktionen im Umkreis.
  3. Auf „Mitmachen" tippen → die Aktion landet in deinen Missionen.

Nichts zu sehen? Prüfe: gleiche Gruppen-Code-Schreibweise bei allen? Cloud aktiv (☁️)? Bei „öffentlich": Standort erlaubt und im Umkreis?

Teil 5 · Werden meine Fotos gespeichert?

Ja – auf deinem Gerät. Ins Internet gehen Fotos nur in zwei Fällen:

  • Auf deinem Gerät: Jedes Beweisfoto wird lokal gespeichert (Browser-Speicher IndexedDB). Es bleibt da, bis du es löschst (Backup/Restore im Profil).
  • In der Gruppe: Geteilt werden nur die Fund-Daten: Artname, Zeit, gerundeter Standort (gefährdete Arten noch gröber), Status, Punkte, Anzeigename, Gruppencode. Fund-Fotos werden nicht in die Cloud hochgeladen.
  • Fall 1 – Bestimmung mit Pl@ntNet: Bei der KI-Quelle „Automatisch" oder „Pl@ntNet" wird das Foto zur Bestimmung an Pl@ntNet geschickt (bei „Pflanze genau bestimmen" bis zu fünf Fotos). Wer das nicht möchte, wählt „On-Device KI".
  • Fall 2 – Monitoring-Foto teilen: Ein Vorher/Nachher-Foto, das du ausdrücklich mit der Gruppe oder öffentlich teilst, wird hochgeladen. Auf „privat" bleibt es auf dem Gerät.
  • Für die Wissenschaft: Nur wenn du aktiv exportierst (Darwin-Core/CSV) oder zu iNaturalist sendest, gehen Daten weiter.
Kurz: Fotos bleiben auf dem Gerät – außer zur Bestimmung bei Pl@ntNet und wenn du ein Monitoring-Foto ausdrücklich teilst. Details: Datenschutzerklärung.
