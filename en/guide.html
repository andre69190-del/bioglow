Guide: groups & missions

How to take part together – join or create a group and set up a mission. For students.

The most important thing first: BIOGLOW saves everything on your device first. For others to see your finds or actions, you all need the same group code. The cloud is already set up – you don’t need to install anything or enter any keys.

Rule of thumb: No group code = only you can see it. Same group code = everyone in the group can see it.

This explains three things that often cause confusion:

  • “I created an action, but nobody can see it.” → It was local (Only me) – or you didn’t have a group code yet.
  • “My group can’t see my finds.” → You spelled the code differently, or you were offline.
  • “Where do I enter a Supabase URL?” → Nowhere. The app says: “☁️ Central cloud active – no setup needed.”

Part 1 · Create a group (once, one person)

A group exists as soon as someone makes up a code and the others type it in. That’s all.

  1. Make up a code – ideally an adult does this. Not too easy to guess, lower case, no spaces.
  2. Give the code to everyone in the group (on paper or by messenger). Don’t post it publicly online – anyone with the code can see the group.

✅ Done – the group exists as soon as the first person types in the code.

💡 You don’t need “🔧 For teachers / advanced”. That is only for schools that use their own cloud instead of the central one.

Part 2 · Join a group (everyone, 30 seconds)

  1. In BIOGLOW: Profile → Class & cloud.
  2. It says “☁️ Central cloud active – no setup needed.”
  3. In the “Group/class code” field, type the code exactly the way everyone uses it.
  4. Below it you’ll see “You are in group …”, and further down “☁️ Cloud active”.

If it doesn’t work:

  • It doesn’t say “Central cloud active” at the top? Close the app completely and open it again.
  • Is the code spelled exactly the same as everyone else’s? Upper/lower case and hyphens matter.
  • Finds made offline are sent later as soon as you’re back online.

Part 3 · Create a mission/action

a) Ready-made missions – already in the app (Missions tab), e.g. “Create a dead-wood corner”. Just do it and upload a proof photo. Before the photo, the app tells you what needs to be in it.

  • 🍂 in season = the mission fits the current season. These are at the top.
  • ⚠️ Safety = read it first! Near water, with tools or on a ladder only with adults.
  • Litter missions: 📷 before photo → collect → 📷 after photo from the same spot → enter the amount and the number of helpers.
  • Habitat missions (e.g. sowing wildflowers): afterwards you can set up a monitoring point and compare later.

b) Your own action (e.g. litter picking, cleaning up a stream):

  1. Missions tab → “🤝 Create & share an action”.
  2. Enter a title (e.g. “Litter picking at the stream”).
  3. Short description: What? Where? When? (e.g. “Sat 10 am, meet at the bridge”).
  4. Choose “Share with whom?”:
    • Only me (local) – stays on your device. Others can’t see it.
    • My group (by code) – everyone with the same group code can see it. (Cloud needed.)
    • Public – everyone nearby – all users within the chosen radius. (Cloud needed.)
  5. Tap “Create action”.
⚠️ Are “Group” and “Public” greyed out? Then the group code is still missing → do Part 2 first. Otherwise you can only choose “Only me” and nobody else will see the action.

Part 4 · Find shared actions & join in

  1. Missions tab → “🌍 Shared actions (group / nearby)”.
  2. You’ll see actions from your group (same code) + public actions nearby.
  3. Tap “Join” → the action is added to your missions.

Nothing there? Check: is the group code spelled the same by everyone? Is the cloud active (☁️)? For “public”: is location allowed and are you within the radius?

Part 5 · Are my photos saved?

Yes – on your device. Photos only go online in two cases:

  • On your device: every proof photo is saved locally (browser storage, IndexedDB). It stays there until you delete it (backup/restore in your profile).
  • In the group: only the find data is shared: species name, time, rounded location (even coarser for endangered species), status, points, display name, group code. Find photos are not uploaded to the cloud.
  • Case 1 – identification with Pl@ntNet: with the AI source “Automatic” or “Pl@ntNet”, the photo is sent to Pl@ntNet for identification (up to five photos with “Identify a plant precisely”). If you don’t want that, choose the on-device AI.
  • Case 2 – sharing a monitoring photo: a before/after photo that you explicitly share with your group or publicly is uploaded. Set to “private”, it stays on the device.
  • For science: data is only passed on if you actively export it (Darwin Core/CSV) or send it to iNaturalist.
In short: photos stay on the device – except for identification with Pl@ntNet and when you explicitly share a monitoring photo. Details: privacy policy (in German).
